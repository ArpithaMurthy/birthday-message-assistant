# Privacy policy draft

Last updated: September 11, 2026

Moments Remembered is designed to work locally on the user's device.

## Data used

The app stores names, birthdays, relationships, optional phone numbers, optional personal notes, reminder preferences, and completion history entered by the user.

## Storage and sharing

This information is stored in the app's local device storage. The current version has no user account, backend, cloud synchronization, analytics, advertising, or developer-operated data collection. Message text is handed to a messaging application only when the user selects the composer action.

## Notifications

The app schedules local notifications on the device. Notification permission can be revoked in system settings.

## Deletion

Individual people can be removed inside the app. Removing the app deletes its local data, subject to operating-system backup behavior.

## Future changes

Contact import, cloud backup, AI generation, analytics, advertisements, affiliate commerce, or account features will require this policy and the relevant store disclosures to be updated before release.
